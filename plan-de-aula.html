El curso

La cámara como sensor, el modelo como procesamiento

  • Esta electiva es IoT, orientada a Visión Artificial aplicada a IoT (AIoT / Edge Vision): el mismo pipeline de siempre, con otro tipo de sensor.
  • El pipeline no cambia: sensor → procesamiento → red → acción. Lo que cambia es el sensor — ahora es una cámara — y la capa de procesamiento, que aquí es un modelo de visión artificial.
  • Curso de enfoque práctico: se trabaja sobre modelos y pipelines de visión, sin diseño de circuitos ni electrónica análoga.

Unidad 01 · Fundamentos de IoT

Arquitectura del pipeline AIoT

  1. 01Percepción (sensor)Cámara RGB, de profundidad o térmica: el sensor ahora captura una imagen en vez de un solo valor analógico
  2. 02Procesamiento (edge)Modelo de visión artificial corriendo en el dispositivo: detección, clasificación o segmentación en tiempo real
  3. 03Red (conectividad)Se transmite el resultado del modelo — una etiqueta, una coordenada, una alerta —, no el video crudo
  4. 04Acción (actuador)La decisión del modelo dispara una acción: un relé, una notificación, un sistema de control

Mismo pipeline del IoT clásico — sensor → procesamiento → red → acción — con visión artificial en la capa de procesamiento
